# atv4

## Форк: диапазон лет в библиотеке

Это форк официального TVML-приложения kino.pub для Apple TV
(`kpapplication/atv4`). Отличия от апстрима:

- В «Библиотеке» вместо одного фильтра «Год» два: **«Год с»** и **«Год до»**.
  В API уходит один параметр `year=FROM-TO` (формат из документации
  `GET /v1/items`). Список «до» не предлагает годы раньше выбранного «с» и
  наоборот.
- `js/settings.js` не падает без `process.env` (в TVJS его нет), поэтому
  приложение работает прямо из исходников без сборки.
- `tools/build.js` собирает однофайловую версию в `dist/` (как на appkp.cc).
- `tools/test-year-range.js` проверяет логику фильтра в Node без приставки.

### Как запустить на Apple TV

1. Выложить содержимое репозитория (или `dist/` после `node tools/build.js`)
   на любой HTTPS-хостинг, например GitHub Pages. По адресу
   `https://<хост>/application.js` должен отдаваться скрипт.
2. В приложении MicroIPTV на Apple TV указать этот адрес как «плейлист»
   (так же, как сейчас указывается `appkp.cc`).
3. На вопрос «Открывать автоматически при запуске приложения?» ответить «Да».

### Обновление из апстрима

```bash
git fetch upstream
git merge upstream/main
node tools/test-year-range.js
```
